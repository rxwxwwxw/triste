# F01 — reproducible baseline

Hypothesis: the existing equal-output acceptance runner supplies a reproducible
baseline; historical ratios must be replaced with current measurements.

Contract: no parser changes, no default changes, and no performance promotion.
Candidate files: baseline wrapper, captured JSON and this task record.

Run `python3 scripts/baseline.py` from the checkout. This runs the existing
`performance_gate.py` with its full default corpus, three independent runs and
seven samples per case. The wrapper bounds execution to 1800 seconds and 4 GiB
address space. A completed ratio failure is baseline evidence, not a runner error.
The manifest records compiler/version/flags (in buildLog), CPU, revision, dirty
state, source hashes, command, report hash and gate counts. Raw samples remain
in `performance/results/F01-baseline.json`.

Existing scaling commands are `bash scripts/recursion-scaling.sh` (one backend,
memo policy and instrumentation cohort) and `bash scripts/recursion-matrix.sh`
(all combinations). Their restoration/extension belongs to F03.

Rollback: remove these artifacts and wrapper; runtime is unchanged.
