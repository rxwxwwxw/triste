# R07 — evaluate combination and stop criteria

Evaluate whether narrower memo invalidation (R03) and shared output snapshots (R06)
can or should be combined, promoted to default, or kept as isolated experiments.

Prerequisite check:
- R03 (narrow invalidation) was evaluated and REJECTED: while direct recursion showed minor gains,
  sibling rule visits became quadratic with 11–12× performance regressions under the stop rule.
- R06 (shared output snapshots) succeeded in eliminating quadratic snapshot copying for deep
  recursion, but introduced a 5–25% fixed overhead on normal flat grammars (JSON, CSV, PEG),
  meaning it could only be kept as an explicit opt-in policy (`-version=NPeggedSharedOutput`),
  never promoted as a default.

Evaluation & Decision:
1. Since R03 was rejected and rolled back, a 2×2 combination {new invalidation × new snapshots}
   is unviable and cannot be promoted.
2. R06 remains available as an explicit opt-in build configuration for deep recursive record workloads,
   leaving standard parser defaults unaffected.
3. Lane R (recursive scaling) is complete.
