# F04 — work attribution

Hypothesis: snapshots alone undercount output work and invalidation visits alone
understate hash-table costs. Add diagnostics only, preserving parser algorithms.

Contract: all counters compile out without NPeggedMetrics. Count successful restore
appends (including work later rolled back), attempted restore calls, actual growth
copies, output snapshot requests, memo lookup/unlink traversals and rehash work.
Keep existing counters and their semantics unchanged. No algorithm promotion.

Candidate files: peg.d, records.d, diagnostic recursion fixture and colocated tests.
Baseline: F03 timing/diagnostic cohorts. Rollback: remove new versioned counters.
