# R02 — bounded memo dependency diagnostics

Hypothesis: logging direct active-seed reads alone misses dependencies propagated
through completed memo hits. Capture creation, evaluation, active/completed hits,
seed growth, completion and broad retirement events with deterministic per-entry
IDs. Derive conservative per-seed dependency edges offline and compare them with
retirements before considering any narrower invalidator.

Contract: NPeggedDependencyTrace only; no invalidation changes. Caller-owned fixed
trace storage; saturation marks a trace incomplete without changing parse status.
Trace IDs never wrap. Repeated equivalent parses yield identical event streams.
Diagnostic fields and event calls are absent from ordinary timing builds.

Fixtures must cover direct/indirect/mutual/nullable recursion, cached transitive
reads, nested active heads and overlapping positions. Keep output/trace/action,
CTFE and finite-budget behavior under the differential suite. An incomplete trace
cannot justify keeping any entry. Retain broad invalidation throughout R02.

Candidate files: peg.d, targeted fixtures/runner/analyzer, results and this task.
Rollback: remove the opt-in diagnostics; parsing defaults remain unchanged.
