# X02 — Evaluation of Ordinary-Rule Phrase Caches (0/1/2/4/8 Entries)

## 1. Hypothesis & Task Objective

In packrat parsers, full memoization stores every rule evaluation in an unbounded hash table to support seed growth for left recursion and avoid redundant parsing. However, full memoization imposes high allocation overhead and cache misses on ordinary (non-left-recursive) rules.

Milestone X02 investigates decoupling ordinary-rule caching from mandatory left-recursion state via optional bounded phrase caches of size $C \in \{0, 1, 2, 4, 8\}$.
Hypothesis:
1. Under adversarial shared-prefix workloads ($M$ choice branches sharing prefix $L$), an $N$-entry phrase cache ($N \ge 1$) eliminates $O(M \cdot L)$ rescans, yielding dramatic speedups.
2. Under interleaved backtracking ("ping-pong" rescans between $K$ distinct positions), a cache with $N < K$ entries thrashes (0% hit rate with update overhead), while $N \ge K$ recovers full hit rates.
3. On linear (non-backtracking) workloads, phrase cache lookups add unnecessary overhead with 0% hit rate, degrading throughput relative to $N=0$.

## 2. Experimental Design & Workloads

Evaluate 5 capacity policies: $C \in \{0, 1, 2, 4, 8\}$.
- **Adversarial Shared Prefix Workload:** Ordered choice with $M$ alternatives evaluating rule $R$ on a long shared prefix before failing at the final character.
- **Interleaved Ping-Pong Workload:** Grammar that evaluates rule $R$ alternating between position $p$ and $p + \Delta$, testing cache eviction and thrashing boundaries across capacities.
- **Linear Non-Backtracking Workload:** Grammar matching straightforward sequential tokens where every rule call is at a monotonically advancing position (measuring pure lookup overhead).

## 3. Metrics

- Parsing time (ns / parse)
- Cache hit rate (% hits vs total calls)
- Memory allocation / retention
- Rescan avoidance ratio

## 4. Rollback & Deployment Boundary

X02 is an evaluation ticket. Phrase caching must be tested behind an opt-in experimental template/configuration, evaluated under adversarial and baseline benchmarks, and documented with an experiment memo and recommendations before any production default changes.
