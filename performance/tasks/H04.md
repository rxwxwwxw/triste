# H04 — rule-local conservative memoization

Keep defaults unchanged under an explicit NPeggedLocalMemo experiment. H02 effects
are necessary but insufficient: removing memoization for a pure unbounded scanner
can worsen overlapping-backtracking scaling. First prove bounded work independent
of input size across the complete local call closure. Preserve all cyclic,
unknown, actionful, parameterized and unbounded rules, including mandatory direct
and indirect recursion entries. Repeated bounded work remains bounded per call;
existing parent memoization and seed invalidation stay intact.

The public API entry must separately be known and effect-free. Arbitrary opaque
or actionful callers can observe changed steps/depth or modify input/limits.
Retain the exact reference policy under tracing, finite context or actual arena
budgets, custom allocators, CTFE and unproven composition. Propagate permission
through the existing isolated tree fallback only after checking outer budgets.
Full memo and no memo are unchanged. Do not silently alter scalar/direct lowering.

Test first: full memo equals the existing selective policy on the deliberately
mixed fixture; compare status, positions, exact nodes/full trees, trace/actions,
finite budgets and allocation charges, borrowed/owned records, predicates,
backtracking, pure consuming cycles, direct/indirect recursion and opaque callers.
Positive counters must show fewer memo calls and requested bytes. Benchmark long
unbounded overlapping scans as scaling controls and roll back on worse scaling.
