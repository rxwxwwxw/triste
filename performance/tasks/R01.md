# R01 — isolate recognition invalidation scaling

Hypothesis: the current unlinked invalidator makes direct/indirect recognition
linear in the existing chain corpus; quadratic record costs must not be attributed
to recognition. Extend sizes to 8192 terms to test that inference.

Contract: no runtime changes, output snapshots exactly zero, full/selective memo
and combinator/direct backends, valid and invalid suffixes. Collect seed growth,
visits, retirements, hash lookup/unlink/rehash work and retained/requested arena bytes.
Timing: three executions × seven samples, 64 parses/sample. Counters: a separate
instrumented binary with one parse/case. Timeout 60 seconds and address space 4 GiB.

Command: `python3 scripts/recognition-scaling.py performance/results/R01`.
Files: recognition fixture, runner, task/report/raw evidence only.
Rollback: remove diagnostic artifacts; parser algorithms and defaults are unchanged.
