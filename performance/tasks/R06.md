# R06 — opt-in shared snapshots in pure recursive records

Hypothesis: immutable replay-span provenance lets memo seed snapshots reuse known
unchanged output, removing repeated snapshot freezing and retained snapshot bytes.
Flat output replay still writes every output node; measure it separately rather
than claiming all quadratic record work disappears.

Scope: records.d, peg.d, output tests, and one generated grammar eligibility enum.
The tiny grammar.d addition proves a closed, action-free, parameter-free grammar
with left recursion; runtime cannot infer effects from a function pointer. Keep
broad memo invalidation untouched. R03 remains rejected.

Explicit build policy NPeggedSharedOutput and ParseContext.sharedOutput opt-in.
Only compiled compact selectors in eligible grammars can enable it. Initially
require maximum step/depth/parse/output arena limits, standard allocators and no
semantic tracing; every unsupported mode/budget uses the existing flat path.
Ownership (borrowed/owned input), selector identity and failure offsets stay exact.

Proof boundary: record immutable replay spans only after successful complete
replay. Rollback discards spans crossing its checkpoint, finish invalidates a span
containing the mutated node, and mutable nodes exposure discards all provenance.
Snapshot composition reuses only complete unchanged spans; unproven nodes are
frozen with explicit earlier-parent attachments. Never infer a stable prefix from
seed growth. Immutable old handles remain valid for the owning parse arena.

Reuse arena-backed replay workspace geometrically within a parse; keep R05's
public one-shot replay API and budget behavior. No GC or manual cleanup.

Baseline/candidate: tests/shared_output.d via scripts/shared-output-check.sh;
then a bounded optimized matrix comparing unchanged reference, compiled-off
control and opt-in, with separate NPeggedMetrics builds. Include flat direct and
indirect chains, nested/sibling growth, root/all projections, valid/trailing
failures, normal PEG/CSV/JSON controls, and both memo policies/backends. Preserve
raw source/compiler hashes, timing samples (3 runs x 7), memory and copy counters.

Acceptance: exact status/success/end/failEnd/nodes; suppression/backtracking,
indirect/mutual/nullable recursion, actions/opaque fallback, tracing, finite
budgets and both ownership modes; positive metrics prove real reuse. DMD/LDC,
-vgc, formatting, source coverage and sanitizer/Memcheck gates must pass. Keep
experimental only if measured intended benefits and no unexplained scaling
regressions; otherwise roll back and archive evidence. Commit the failing oracle
before implementation, and keep each milestone separate.

Measured design refinements: retain flat copying below one 4 KiB arena slab;
keep RecordSnapshot at three words so disabled/finite-budget behavior preserves
memo allocation charges. Decode shared handles only inside the enabled internal
buffer; generic public empty snapshots retain their old behavior. The cross-build
oracle exports every record/effect field and inactive arena charge for exact
comparison rather than relying on an output hash alone.

Outcome: retain explicit experimental policy only. The full 48-cohort matrix
passes semantic/resource signatures and shows repeated large-output time and
copy/retention gains across backends/memo modes and sibling growth. Flat replay
and overall timing remain quadratic. Small-case overhead and substantial timing
variation preclude default promotion; worst cases remain in the report. All
source coverage, compiler, -vgc, sanitizer and Memcheck gates passed. See
../results/R06/README.md for exact measurements and limitations.
