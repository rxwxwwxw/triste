# Differential oracle validation

`bash scripts/differential.sh` and `DC=dmd bash scripts/differential.sh` pass.
The standalone runner has a 60-second timeout and 4 GiB address-space limit.
Identical grammar names make full field/trace comparisons possible without
normalizing away observable data. Both full and selective memoization are covered.
The fixture checks every ParseTree field recursively, exact CompactNode arrays,
status/success/end/failEnd in all modes, owned/borrowed input, action order and
count, and exact trace sequences with tracing enabled and disabled.

The corpus includes exhaustive {a,b} inputs through length four, targeted UTF-8,
NUL and high bytes, EOF/truncation, predicates, nested choices, direct/indirect and
nullable left recursion, a longer indirect chain, CTFE tree equality and finite
step/depth/scratch/output limits. Existing tests/runner.d supplies broader nested
recursive direct recognition coverage.

A draft nested-template grammar with `Item <- '(' Item* ')' / 'a'` exposed an
existing LDC attribute-inference failure in the direct selective records path:
`_cursor_Item cannot call non-@nogc recognizeRecordedRule`. The runnable fixture
uses a nonrecursive parenthesized byte sequence; direct/indirect/nullable left
recursion remains in the matrix. This is a compile limitation, not a performance
improvement or proof that all grammars compile. No production fix is included in
F02, which explicitly prohibits production changes.
