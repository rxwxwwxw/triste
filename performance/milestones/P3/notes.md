# P3 — Certified two-byte dispatch emitted in direct cursors — COMPLETE (exact; default for the direct backend)

Change: the ordered choice of 1-2 byte literals with overlapping FIRST bytes (F4's `literalChoice2`, previously opt-in via
`NPeggedFirst2`) is now generated by the direct backend and emitted natively in cursors (`emitDirect`, branch on
`literalChoice2!(...)`): `plan.slot[byte]`/`plan.winner[row][second byte or EOF]` are tested inline, the hit sets `end`
from a per-alternative length table, and everything the ordered choice would have recorded is replayed:
- hit: the failures of the skipped earlier alternatives (`plan.skip`: offset 0, or offset 1 when an earlier alternative shares
  the first byte); this matters because a step limit can end the parse before the final `failEnd` merge hides it;
- miss: every alternative failed; failure at the position, or one byte later when some alternative starts with the input byte;
- accept clone: no failure replay. Literals and choices charge no work units (docs/WORK_UNITS.md), so no ticks are replayed.
The combinator backends keep the plain ordered choice (unless `NPeggedFirst2`); `literalChoice2.opCall` was corrected the same
way (it also stopped charging the winner's index+1 ticks of the old model).

Found while testing: the first version, copied from F4's claim that skipped failures cannot change the final `failEnd`,
differed from the ordered choice under step limits (`<=<=` with limit 5: failEnd 2 vs 0). Brute force over all inputs up to
length 6 over `{<,=,!,x}` with limits 0..23 (131,064 comparisons, combinator vs direct) now matches; the same enumeration is
in `tests/differential.d` (inputs up to length 5, limits 0..19, all output modes, tracing on/off).

New benchmark family `Ops` (`choices`): `BenchOps` grammar (24 operators of 1-2 bytes), handwritten twin
`benchmark/handwritten/ops.d` (unit-tested), workloads Short/Empty/Invalid/Pairs/Truncated/Long/LongInvalid in
validation and accept modes (no records modes).

Measured (Apple M1, LDC 1.43, direct backend, 3 interleaved repetitions x 9 samples x 20000; raw JSON here;
before = same tree without the cursor-native table): Short 95-134 -> 47-55 ns (ratio vs handwritten 5.9-6.9 -> 2.9),
Empty 27-31 -> 15-18 (3.7 -> 2.1), Invalid 36-39 -> 22-23 (3.6 -> 2.2), Pairs 62 -> 31-33 (4.3 -> 2.1),
Truncated 50 -> 34 (2.6 -> 1.7), Long (7,424 operators) 71.1 -> 43.5 us (3.8 -> 2.3), LongInvalid 71.2 -> 43.5 us.
The F4-as-combinator version (flag) had made the tiny cases 2-3x slower (Empty 77 ns); the native miss path fixes that.
The family stays above 1.5x: per operator the remaining cost is the `Op` and `Space` rule calls, the loop attempt and the
whitespace scanner call.

Tests: peg.d plan/skip table checks, dense differential (above) with and without `NPeggedFirst2`, A4 + 25-module unit tests,
scripts/build.sh and the fixture checks on LDC. DMD, sanitizers, Valgrind, coverage tooling: not run on this host.
